# Kene John — Portfolio

Portfolio van Kene John, junior software developer (MBO 4 Software Development).

## Snel clonen en starten

Je hebt [Git](https://git-scm.com/) en [Node.js](https://nodejs.org/) (LTS) nodig.

```bash
git clone https://github.com/John07-Coder/Kene-john-portfolio.git
cd Kene-john-portfolio
npm install
npm run dev
```

Open daarna in je browser: [http://localhost:5173](http://localhost:5173)

Met SSH (als je GitHub-keys hebt ingesteld):

```bash
git clone git@github.com:John07-Coder/Kene-john-portfolio.git
cd Kene-john-portfolio
npm install
npm run dev
```

## Andere commando’s

```bash
npm run build    # productie-build in dist/
npm run preview  # lokale preview van de build
```
